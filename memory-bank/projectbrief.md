# Project Brief

## Назначение

`HW5_MCP1` - учебный локальный MCP-сервер на Node.js/TypeScript для подключения к агенту в VS Code/Cursor. Проект демонстрирует, как поднять MCP server через `stdio`, зарегистрировать собственные tools и возвращать структурированные JSON-ответы.

Это не веб-приложение и не долгоживущий HTTP-сервис. Основной runtime-сценарий: IDE запускает собранный `dist/index.js`, а агент вызывает зарегистрированные MCP tools.

## Что реализовано

- MCP-сервер `hw5-local-mcp` версии `1.0.0`.
- Транспорт `StdioServerTransport`.
- Три tools:
  - `doc_lookup` - поиск по локальному markdown-файлу `docs/local-docs.md`.
  - `project_search` - поиск текста по файлам проекта внутри workspace.
  - `safe_command` - запуск только разрешённых npm-команд.
- Конфигурация IDE в `.vscode/mcp.json`.
- Документация и примеры вызова tools в `README.md`.

## Ключевой пользовательский сценарий

1. Пользователь устанавливает зависимости через `npm install`.
2. Пользователь собирает проект через `npm run build`.
3. VS Code/Cursor запускает MCP-сервер по `.vscode/mcp.json`.
4. Агент вызывает tools сервера и получает JSON-подобные структурированные ответы.

## Границы проекта

- Проект ориентирован на учебную демонстрацию MCP, а не на production-ready сервер.
- Все основные возможности сосредоточены в одном исходном файле `src/index.ts`.
- Нет отдельного API поверх HTTP/SSE, базы данных, UI или внешних сервисов.
