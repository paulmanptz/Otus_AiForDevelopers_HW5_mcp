# Product Context

## Зачем существует проект

Проект нужен как учебная демонстрация Model Context Protocol server для AI-агента в IDE. Он показывает минимальный, но полезный набор возможностей:

- локальная документация доступна агенту через tool;
- агент может искать по файлам проекта через контролируемый интерфейс;
- агент может запускать ограниченный набор безопасных dev-команд.

## Для кого

Основной пользователь - студент или разработчик, который изучает MCP и хочет увидеть рабочую интеграцию с VS Code/Cursor на небольшом TypeScript-проекте.

## Пользовательская ценность

- Можно быстро понять, как зарегистрировать MCP-сервер в IDE.
- Можно увидеть, как описывать tool schemas через Zod.
- Можно потренироваться в вызове tools из IDE chat.
- Можно использовать проект как основу для более сложного локального MCP-сервера.

## Ожидаемый UX

Пользователь не запускает сервер вручную в обычном сценарии. После `npm install` и `npm run build` IDE сама стартует сервер по `.vscode/mcp.json`.

В чате пользователь явно просит агента вызвать нужный MCP tool, например:

```text
Use the hw5-local-mcp project_search tool to find where safe_command is implemented.
```

Успешный tool call возвращает JSON-структуру с результатами.

## Не-цели

- Не строить полноценный production MCP platform.
- Не выполнять произвольные shell-команды.
- Не индексировать весь workspace как поисковый движок.
- Не заменять IDE-native search, terminal или test runner.
