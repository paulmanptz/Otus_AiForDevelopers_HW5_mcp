# Memory Bank

Эта папка хранит рабочую память по проекту `HW5_MCP1`.

Рекомендуемый порядок чтения:

1. `projectbrief.md` - назначение и границы проекта.
2. `productContext.md` - пользовательская ценность и UX.
3. `techContext.md` - стек, команды, конфиги и runtime.
4. `systemPatterns.md` - архитектура и важные паттерны реализации.
5. `activeContext.md` - текущий контекст, риски и следующие шаги.
6. `progress.md` - что готово, что частично готово и как проверять проект.

Перед изменениями в проекте сначала перечитай `activeContext.md` и `systemPatterns.md`.
